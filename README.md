# GTA IV Drive-By Pre-Aim
A GTA IV ASI plugin that allows the player to pre-aim during vehicle drive-bys by holding RMB before firing. This makes it similar to GTA V.\
\
For GTAIV The Complete Edition Only.

# Behavior

Vanilla:\
\
RMB + LMB → drive-by

Modified:\
\
RMB → prepare/aim\
LMB → fire

# How to install
Grab [latest]() archive and move GTAIVDriveByPreAim.IV.asi in the root or "plugins" folder.
